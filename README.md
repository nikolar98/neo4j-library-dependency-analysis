# Neo4j Library Dependency Analysis

Graph database project focused on modeling software library dependencies and analyzing security vulnerabilities of a Spring Boot Rent-A-Car Management System using Neo4j, Cypher, Maven Dependency Tree, Snyk vulnerability reports, CWE, CAPEC, and Graph Data Science concepts.

## Features

* Software dependency graph modeling
* Dependency relationship analysis
* Security vulnerability analysis
* CWE weakness mapping
* CAPEC attack pattern analysis
* Mitigation measures modeling
* Degree centrality analysis using Neo4j GDS
* Graph visualization and dependency exploration

## Technologies

* Neo4j
* Cypher
* Graph Data Science (GDS)
* Maven
* Spring Boot
* Snyk
* CWE
* CAPEC

## Analysis Goals

The project analyzes software library dependencies extracted from a Spring Boot application in order to:

* identify vulnerable libraries
* analyze dependency relationships
* detect critical components
* map vulnerabilities to CWE weaknesses
* map weaknesses to CAPEC attack patterns
* model mitigation measures

## Example Analyses

* Library dependency graph visualization
* Vulnerable dependency identification
* Degree centrality analysis
* Library → CWE → CAPEC relationship analysis
* Mitigation strategy modeling

## Purpose

Academic project focused on graph databases, cybersecurity concepts, dependency analysis, and Neo4j-based graph analytics.
